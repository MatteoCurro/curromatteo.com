# CasaFlix Pages mirror

Publicazione isolata di CasaFlix tramite GitHub Pages; contiene HTML e JSON del progetto scageto/CasaFlix.
Il workflow sulla branch predefinita sincronizza periodicamente index.html, data/movies.json e data/tv.json dal repository originale.
La prima versione carica i JSON direttamente dall'upstream, prima che il workflow effettui la sincronizzazione completa.

In GitHub: Settings → Pages → Deploy from a branch → casaflix-pages / (root).

Fonte originale: https://github.com/scageto/CasaFlix
